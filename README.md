# Lucas Portfolio

Personal bento-style portfolio built with Next.js App Router.

## Stack
- Next.js 15 + React 19 + TypeScript
- Tailwind v4
- GSAP, Lenis, Matter.js, react-globe.gl
- next-cloudinary + yet-another-react-lightbox
- PostHog analytics

## Run locally
```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

## Integrations included
- GitHub stats
- WakaTime stats
- Spotify now playing/top tracks
- Cloudinary photos

## Hosting
Deploy on Vercel and attach `lucas-obrien.com` in project settings.
